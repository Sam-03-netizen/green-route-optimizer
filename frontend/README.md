# Frontend Dashboard

This folder contains the optional React-based dashboard for manually interacting with the Green Route Optimizer environment.

## Purpose
The frontend is included for:
- manual environment testing
- task visualization
- step-by-step action execution
- demo presentation

## Run locally

```bash
npm install
npm run dev
```

By default, the frontend expects the FastAPI backend to be running at:

```text
http://127.0.0.1:8000
```
